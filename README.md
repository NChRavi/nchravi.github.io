# Academic & Executive Web Portal — Dr. N. Ch. Ravi

A modern, responsive, and high-performance academic portfolio and course hub built for **Dr. N. Ch. Ravi**, Professor in the Department of Computer Science & Engineering at **ACE Engineering College, Hyderabad**.

---

## 🌟 Key Features

- **Single-Page Application (SPA) Architecture**: Dynamic, client-side tab switching for seamless user experience without page reloads.
- **Tailwind CSS Styling**: Custom academic-executive color palette, glassmorphism cards, and fluid layouts.
- **Dark Mode Support**: Full light and dark theme toggling with system preference support and smooth transitions.
- **Interactive Course Management**:
  - Semester-based filtering (All, Semester I, Semester II).
  - Dynamic syllabus modals for active courses.
  - Resource download handlers.
- **Academic & Research Highlights**: Dedicated sections for research publications, patents, centers of excellence (Microsoft, IBM, CISCO, Texas Instruments, AMD), and qualifications.
- **Contact Form**: Built-in interactive contact interface with office consultation hours and location details.
